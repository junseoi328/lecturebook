# 렉처북 v0.9: 강의자료를 시험 대비 책으로

렉쳐노트를 올리면 한국어로 핵심만 정리하고(요점마다 근거 페이지), 쌓인 강의를 한 권의 한글 PDF로 묶고,
시험 형식과 족보를 반영해 문제를 만들고 채점하는 공부 도구.

## 계속 작업할 폴더

이 폴더(`C:\Users\User\Desktop\lecturebook`)가 유일한 작업본이다. 버전별 폴더나 ZIP으로 옮기지 않는다.
`site/`의 HTML·CSS·JS를 수정하고, 같은 폴더의 `dist/`를 실행본으로 유지한다.
이 폴더에는 Git 이력을 시작해 두었다. 이후 수정은 여기서 계속하고, `dist/`와 테스트 스크린샷은 생성물로 취급한다.

```powershell
cd C:\Users\User\Desktop\lecturebook
node tools/dev.js
```

표시되는 `http://127.0.0.1:4173/`을 열면 된다. `site/` 파일을 저장할 때마다 자동으로 다시 빌드되고 브라우저가 새로고침된다.
개발 서버 없이 쓸 때는 `node build.js` 후 `dist/index.html`을 열면 된다. 이 경우 변경 후 다시 빌드하고 새로고침해야 한다.
자료·정리 기록은 브라우저 저장소에 남으므로, `file://`에서 로컬 서버로 주소를 바꾸기 전에는 화면의 백업 기능으로 내보내 두는 편이 안전하다.

## v0.9 바뀐 점
- **화면 정리:** 겹겹이 쌓인 초록·네온·무한 애니메이션 대신 차분한 잉크·라벤더·코랄 시스템으로 바꿨다. 홈에는 필요한 3개 AI 작업만 소개하고, 전체 10개 역할은 설정 안에 유지한다.
- **빈 영역 수정:** 스크롤 전 카드가 투명하게 보이던 진입 효과를 제거했다. 포인터를 움직일 때마다 히어로 전체를 다시 그리던 효과도 제거했다.
- **한 폴더 개발:** 의존성 설치 없이 로컬 개발 서버가 `site/` 수정 감지 → 같은 `dist/` 갱신 → 브라우저 새로고침을 처리한다. 서버는 이 PC(`127.0.0.1`)에만 열린다.

## v0.8 바뀐 점
- **무료 공급자 선택 폭 확대:** Mistral, Cerebras, SambaNova를 더해 Gemini, Groq, OpenRouter, 로컬 Ollama까지 총 7곳을 지원한다. Claude 아티팩트에서는 내장 AI도 사용한다.
- **작동 여부 분리 표시:** 키 입력만으로 성공을 선언하지 않는다. 공급자별 `연결 확인`을 눌러 짧은 실제 요청이 성공하면 `사용 확인`으로 표시한다.
- **강의 질문:** 정리한 강의에서 질문하고, AI가 참조한 원문 페이지와 근거 부족 여부를 함께 본다. 질문·답은 저장하지 않는다.
- **더 빠른 설정 화면:** 모델 목록을 열 때 외부 모델 검색 요청을 하지 않는다. 10개 역할은 10개 독립 모델이 아니라는 점을 화면에서 분명히 안내한다.
- **키 노출 축소:** Gemini 키는 URL 대신 요청 헤더에 넣는다. 모든 키는 탭 메모리에만 두며 백업에 넣지 않는다.

> 무료 한도와 모델 제공 여부는 공급자가 바꿀 수 있다. 공급자별 브라우저 직접 접속(CORS), 실사용 응답 품질은 사용자 키가 없어 확인하지 못했다. `연결 확인` 결과를 먼저 보자.

## 무료 AI 연결
- **바로 사용:** Claude 아티팩트 링크에서는 내장 AI가 기본으로 동작한다.
- **선택 연결:** 화면 오른쪽 위 `AI 설정`에서 Gemini, Groq, OpenRouter, Mistral, Cerebras, SambaNova의 무료 플랜 키 또는 내 컴퓨터의 Ollama를 설정한다. 한 곳이면 충분하다.
- **연결 확인:** 키를 입력하고 해당 카드의 `연결 확인`을 누른다. `설정됨`은 키가 있다는 뜻, `사용 확인`은 짧은 모델 요청이 성공했다는 뜻이다. 연결 확인도 공급자 무료 한도를 조금 사용한다.
- **자동 전환:** AI 요청 실패 시 연결한 다른 공급자에 같은 자료를 다시 보낼 수 있다. 민감한 자료는 로컬 Ollama만 연결해서 사용한다. 무료 한도와 제공 모델은 공급자 정책에 따라 바뀐다.
- **개인정보:** 공급자 키는 현재 탭 메모리에만 보관한다. 브라우저에서 직접 보내는 방식이므로 사용자의 브라우저 확장과 개발자 도구에서는 키를 볼 수 있다. 공유 키를 코드에 넣어 공개 배포하면 안 된다.

## 동작 방식
- **AI:** Claude 아티팩트 내장 AI 또는 사용자가 선택한 무료 공급자를 브라우저에서 직접 호출한다. 자체 서버는 없다.
- **저장:** 자료와 결과는 사용자의 브라우저(IndexedDB)에만 저장한다. 백업 파일로 옮길 수 있다.
- **PDF:** jsPDF와 내장 한글 폰트(Noto Sans KR 부분 폰트, 한글 2,350자와 기호)로 브라우저에서 만든다.

## 실행과 빌드
- 개발: `node tools/dev.js` → 표시된 로컬 주소에서 자동 새로고침. AI 기능은 무료 공급자를 연결하거나 Claude 아티팩트에서 열면 켜진다.
- 고성능 실행본: `node build.js` → `dist/index.html` + `dist/font.js`·`book.js`·`translate.js`
- 단일 파일 실행본: `dist/standalone.html`
- 폰트 다시 만들기: `python tools/make_font.py` (fontwork/NotoSansKR.ttf 필요)

Playwright가 설치된 환경에서는 `node tests/browser-smoke.js`와 `node tests/design-regression.js`로 설정·질문·모바일 화면을 점검할 수 있다. `node tests/translate-smoke.js`는 가짜 AI로 번역 PDF 카드(올리기·문단 묶기·첨자와 수식 보존·실패 뒤 재시도·줄이기·내려받기)를 확인한다.
`e2e.py`는 공개 페이지와 비슷하게 외부 접속, eval, 워커를 막은 조건에서 가짜 Claude 응답으로 전체 흐름(업로드 → 정리 → PDF → 시험 형식 → 족보 → 문제 → 채점 → 책 → 새로고침 뒤 유지 → 백업 → AI 없는 환경 → 모바일)을 확인한다. 별도로 무료 AI 팀 단위 테스트 16개를 실행한다.
`perf.test.js`는 무거운 문서 도구가 초기 화면에서 제외되고 고성능 실행본이 250KB 예산 안에 있는지 확인한다. 실제 측정 기록은 `PERFORMANCE.md`에 있다.

## 알려진 한계
- 실제 외부 무료 모델 응답 품질, 브라우저 CORS, 공급자별 사용 한도는 키가 없어 검증하지 않았다. 무료 플랜 가입 여부도 계정·지역에 따라 다를 수 있다.
- HWP, 옛 PPT·DOC 형식은 못 읽는다. PDF로 바꿔서 올린다.
- PDF 폰트에 없는 글자(한자, 드문 한글)는 ?로 표시된다.
- 브라우저 직접 연결 방식은 개인 사용과 프로토타입에 적합하다. 공개 서비스에서는 사용자 키를 받지 말고 자체 서버에서 비밀키를 보호해야 한다.
