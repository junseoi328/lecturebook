# 제품 메모

## 문제
대학생은 매주 받은 렉쳐노트를 AI에 붙여넣고, 정리 형식과 시험 형식을 매번 다시 설명한다. 결과는 대화창에 흩어지고, 시험 직전에 한 권으로 모으기 어렵다. 족보는 따로 분석해야 한다.

## 해결
과목 단위로 자료를 쌓고, 한 번 정한 시험 형식과 족보 경향이 문제 생성과 책 만들기에 계속 반영된다.

## 차별점 (가설, 사용자 테스트로 확인할 것)
1. 요점마다 근거 페이지: AI 환각을 사용자가 바로 확인
2. 족보 분석과 문제 생성이 연결됨: "우리 교수님 스타일" 문제
3. 한 학기 자료가 한 권의 한글 PDF로
4. 자료가 서버에 모이지 않음: 강의자료 저작권, 족보 공유 문제를 피함

## 측정할 것 (포트폴리오 근거)
| 지표 | 방법 |
|---|---|
| 정리 시간 | 기존 방식(AI 대화) vs 렉처북, 강의 1개 기준 |
| 정리 정확도 | 요점 20개 표본의 근거 페이지 대조, 틀린 요점 비율 |
| 재사용 | 한 과목에 강의를 3개 이상 올린 사용자 수 |
| 시험 도움 | 시험 뒤 설문: 예상 문제 적중 체감, 다시 쓸 의향 |
